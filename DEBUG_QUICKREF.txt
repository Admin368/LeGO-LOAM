┌─ MOST COMMON ISSUES ───────────────────────────────────────────────────┐
│                                                                          │
│ ① RViz displays disabled                                                │
│    → Enable: Velodyne, Surface, Edge Sharp, TF in RViz left panel      │
│                                                                          │
│ ② Wrong sensor configuration                                            │
│    → Check N_SCAN matches your LIDAR (16/32/64/128)                     │
│    → Edit utility.h and rebuild                                         │
│                                                                          │
│ ③ Points filtered too aggressively                                      │
│    → Check debug logs for point counts                                  │
│    → Adjust sensorMinimumRange, groundScanInd in utility.h              │
│                                                                          │
│ ④ RViz Fixed Frame wrong                                                │
│    → Set to "map" or "camera_init"                                      │
│                                                                          │
│ ⑤ Need to wait for initialization                                       │
│    → Wait 10-20 seconds for data to accumulate                          │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
