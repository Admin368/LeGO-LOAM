┌─ QUICK SETUP ──────────────────────────────────────────────────────────┐
│                                                                          │
│  1. Enable in utility.h:                                                │
│     #define LEGO_LOAM_DEBUG 1                                           │
│     #define LEGO_LOAM_FILE_DEBUG 1                                      │
│                                                                          │
│  2. Rebuild:                                                             │
│     cd /catkin_ws && catkin_make && source devel/setup.bash              │
│                                                                          │
│  3. Run LeGO-LOAM and bag file (as normal)                               │
│     roslaunch lego_loam run.launch                                       │
│     rosbag play /path/to/bag.bag --clock                                 │
│                                                                          │
│  4. Logs are written to: /tmp/lego_loam_logs/lego_loam_debug.log         │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ VIEWING LOGS (WHILE RUNNING) ─────────────────────────────────────────┐
│                                                                          │
│  # Watch logs in real-time (like tail -f):                               │
│  python3 view_logs.py -f                                                 │
│                                                                          │
│  # Filter by node:                                                       │
│  python3 view_logs.py -f -n ImageProjection                              │
│  python3 view_logs.py -f -n FeatureAssociation                           │
│  python3 view_logs.py -f -n MapOptimization                              │
│                                                                          │
│  # Show last N lines:                                                    │
│  python3 view_logs.py -l 50                                              │
│                                                                          │
│  # Show statistics:                                                      │
│  python3 view_logs.py -s                                                 │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ ANALYZING LOGS (AFTER COLLECTION) ────────────────────────────────────┐
│                                                                          │
│  # Automatic analysis and recommendations:                               │
│  bash collect_logs.sh --run                                              │
│                                                                          │
│  # Or do separately:                                                     │
│  bash collect_logs.sh --collect    # Archive logs with timestamp         │
│  bash collect_logs.sh --analyze    # Analyze most recent session         │
│                                                                          │
│  # Manual analysis of specific log:                                      │
│  python3 analyze_logs.py /tmp/lego_loam_logs/lego_loam_debug.log         │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ UNDERSTANDING THE OUTPUT ─────────────────────────────────────────────┐
│                                                                          │
│  POINT CLOUD FLOW ANALYSIS:                                              │
│  ═══════════════════════════════════════════════════════════════════════ │
│  Shows points at each stage:                                             │
│  • INPUT: Raw points from sensor (~25k-30k)                              │
│  • SEGMENTED: After filtering (~10k-20k)                                 │
│  • FEATURES: Corner/flat surface features (~200-500)                     │
│  • MAP: Global map points                                                │
│                                                                          │
│  HEALTHY EXAMPLE:                                                        │
│  Input: 28,000 → Segmented: 15,000 → Features: 320 ✓                    │
│                                                                          │
│  PROBLEM EXAMPLE:                                                        │
│  Input: 28,000 → Segmented: 15 → Features: 0 ✗ SENSOR CONFIG ISSUE     │
│                                                                          │
│ ───────────────────────────────────────────────────────────────────────  │
│                                                                          │
│  DATA SYNCHRONIZATION CHECK:                                             │
│  ═══════════════════════════════════════════════════════════════════════ │
│  ✓ ImageProjection: 143 messages received                                │
│  ✓ FeatureAssociation: 143 messages received                             │
│  ✓ MapOptimization: 143 messages received                                │
│                                                                          │
│  All nodes should have similar receive/publish counts                    │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ TROUBLESHOOTING ──────────────────────────────────────────────────────┐
│                                                                          │
│  Issue: Logs show very few points (< 100)                                │
│  → Check sensor parameters in utility.h                                   │
│  → Verify N_SCAN matches your LIDAR (16/32/64/128)                       │
│                                                                          │
│  Issue: No features detected (Sharp corners: 0)                           │
│  → Check input point cloud quality                                        │
│  → Verify sensor orientation and mounting angle                          │
│  → Try adjusting feature detection thresholds                            │
│                                                                          │
│  Issue: Nodes not synchronized                                            │
│  → Check ROS master is running                                            │
│  → Verify bag file played with --clock                                    │
│  → Check for clock issues in logs                                         │
│                                                                          │
│  Issue: Logs not being created                                            │
│  → Enable LEGO_LOAM_DEBUG and LEGO_LOAM_FILE_DEBUG in utility.h           │
│  → Rebuild project                                                        │
│  → Check /tmp/lego_loam_logs/ directory exists                            │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

TYPICAL WORKFLOW:

  1. Enable logging in utility.h
  2. Rebuild: catkin_make
  3. Run LeGO-LOAM: roslaunch lego_loam run.launch
  4. Play bag: rosbag play data.bag --clock
  5. View live: python3 view_logs.py -f
  6. Collect: bash collect_logs.sh --collect
  7. Analyze: bash collect_logs.sh --analyze
  8. Review output and fix issues
  9. Disable logging when done: LEGO_LOAM_DEBUG 0
